# Project Bastion

## Controls

- **WASD / arrows** — move
- **1 / 2** — select wall or turret during build phase
- **Left-click** — place during build; attack during the wave
- **Right-click** — remove during build; hold near damage to repair during the wave
- **Space** — start the wave early
- **Escape** — pause or resume
- **R** — restart after victory or defeat
